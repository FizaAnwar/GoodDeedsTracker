# Little Good Things – Good Deeds Tracker

A simple kindness journal where you write down the good things you do each day and watch them add up.

## 🔗 Live demo

**[Open the Good Deeds Tracker](https://fizaanwar.github.io/GoodDeedsTracker/)**

https://fizaanwar.github.io/GoodDeedsTracker/

## Features

- Add a good deed with the button or the Enter key
- Delete a deed you added by mistake
- Live stats for today, this month, this year and all time
- Daily goal of 5 deeds with a progress bar
- History page that groups your deeds by date
- Deeds are saved in your browser (localStorage), so they stay after a refresh
- Blue and white design that works on phones and has a dark mode

## Built with

- HTML
- CSS
- JavaScript

## Run it on your computer

1. Download or clone this repository:
   ```bash
   git clone https://github.com/fizaanwar/GoodDeedsTracker.git
   ```
2. Open the folder.
3. Double-click `index.html` to open it in your browser.
